Принципы проекта

То, что делает из void linux Meow.

Прозрачность

Обновление ядра -- варнинг с прозрачной просьбой запустить dracut --force. Обновление шрифтов -- fc-cache -fv. Ноль фона, сценарий варнинга под каждый post hook.

Ручное управление, но удобное

Для сервисов -- тоже meow

KISS

Один бинарник на Go и конфиг на пять строк. Без 32bit, systemd и elogind

// зона риска

Фирменные дотфайлы

Универсальные конфиги для waybar, foot, mako, wbg, fuzzel. Работают в любом Wayland-WM. Меняется только композитор.

Репозиторий дотфайлов: git.example.com/meow/dotfiles
Готовые конфиги для mango и labwc -- в /etc/motd после установки.
Плейсхолдер: ссылка на зеркало и инструкция по клонированию.
